# v8_debug_overlay_value_color

## Изменения

- Значения в debug overlay теперь рисуются отдельным цветом.
- Названия полей остаются основным цветом текста.
- Цвет значений вынесен в `config/debug.json`.

## Настройка

```json
"overlay": {
  "label_color": [235, 235, 235, 255],
  "value_color": [255, 170, 64, 255]
}
```

## Принцип

Строки вида `FPS: 60` рисуются двумя частями:

- `FPS:` — `label_color`;
- ` 60` — `value_color`.

Строки без двоеточия рисуются целиком как `label_color`.
