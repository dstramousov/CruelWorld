Работает:
- Проект запускается у пользователя.
- Расширенная стартовая карта загружается.
- Маршруты читаются лучше.
- Коммуникатор открывается и закрывается.
- Верхнее меню коммуникатора работает кликом.
- Верхнее меню коммуникатора переключается стрелками Left / Right.

- Из пунктов меню можно вернуться во вкладку “Комуникатор”.
- Выход из игры работает только через `Exit Game` / `Выйти из игры` и подтверждение.

- Длинные строки в левой панели коммуникатора переносятся автоматически.

  `python -m sphinx -b html docs_api/source docs_api/build/html`

Известные проблемы:
- Чанки пока только отображаются как статистическая заготовка, карта всё ещё грузится целиком.
- Часть пунктов меню коммуникатора пока placeholder.
- Тесты добавлены, но в контейнере ранее не удавалось полноценно прогнать `pytest`; локально нужно проверить командой:
  `python -m pytest`
- Sphinx-документация добавлена, но HTML-сборку нужно проверить локально после установки `requirements-dev.txt`.
- UI коммуникатора рабочий, но пока базовый по визуалу.
- Некоторые interaction/fauna markers пока являются маркерами/событиями, а не полноценными объектами поведения.
- Нужно внимательно принять новый очищенный `archive.zip` от пользователя как единственный источник истины перед следующими изменениями.

Какие решения были приняты в этой ветке:
- Параллакс и Mid overlay больше не являются активной задачей.
- `a`, `c`, `g` — это пользовательские утилиты, их нельзя удалять.
- Все используемые игровые кнопки должны выноситься в конфиг.
- `ESC` не должен закрывать игру напрямую.
- Выход из игры должен быть только через коммуникатор и подтверждение.
- Коммуникатор становится центральным интерфейсом:
  - журнал;
  - новая игра;
  - сохранение;
  - загрузка;
  - настройки;
  - выход.
- Вкладка “Комуникатор” должна быть первой и открываться по умолчанию.
- Текст в UI должен переноситься по реальной пиксельной ширине, а не по количеству символов.
- Размеры текста коммуникатора должны настраиваться через `config/game.json`.
- Debug-информация должна выводиться в существующий overlay по `Shift+D`, новый overlay не нужен.
- При любых изменениях кода нужно обновлять:
  - docstrings;
  - tests;
  - `docs/`, если меняется поведение;
  - `.rst` в `docs_api/source`, если меняется структура модулей или публичная документационная структура.
- Sphinx-документация должна оставаться собираемой одной командой:
  `python -m sphinx -b html docs_api/source docs_api/build/html`
