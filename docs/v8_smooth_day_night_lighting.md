# v8_smooth_day_night_lighting

## Что изменено

- Освещение времени суток теперь не переключается скачком между фазами.
- Цветовой overlay интерполируется через `smoothstep`, чтобы переходы были визуально мягче.
- День и ночь остаются стабильными плато.
- Рассвет и закат стали переходными окнами:
  - `dawn_start` -> `day_start`: night -> dawn -> day;
  - `dusk_start` -> `night_start`: day -> dusk -> night.
- Sky tint теперь реально применяется к фону до отрисовки звёзд.
- World tint по-прежнему рисуется поверх мира, а фонарик остаётся поверх затемнения.

## Где настраивать

`config/game.json`:

```json
"day_night_cycle": {
  "phase_ranges": {
    "dawn_start": 5,
    "day_start": 7,
    "dusk_start": 18,
    "night_start": 20
  },
  "tint": {
    "day_world": [255, 255, 255, 0],
    "dusk_world": [255, 226, 186, 22],
    "night_world": [180, 196, 255, 42],
    "dawn_world": [198, 222, 255, 20]
  }
}
```

## Техническая логика

- Внутри рассвета и заката используется трёхточечная интерполяция.
- На границах фаз цвет совпадает с предыдущей стабильной фазой, поэтому визуального скачка быть не должно.
