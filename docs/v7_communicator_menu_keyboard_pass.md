# v7 communicator menu keyboard pass

- Added configurable keyboard navigation for the communicator top menu.
- `LEFT` selects the previous communicator tab.
- `RIGHT` selects the next communicator tab.
- Journal entry navigation with `UP/DOWN` and `W/S` now works only while the `Communicator` tab is active.
- Keyboard tab navigation does not open the exit confirmation dialog automatically; the exit dialog still requires clicking `Exit Game`.
- Added tests for communicator menu wraparound and modal-dialog behavior.
