# v8_new_game_settings_ui_polish

## Изменения

- Экран `Новая игра` теперь показывает курсор ввода имени героя.
- В строке имени выводится счётчик длины `current/max`.
- Ввод имени ограничен `max_hero_name_length` из `config/game.json`.
- Добавлена отдельная подсказка для активного поля имени.
- Экран `Настройки` теперь показывает переключаемые значения как `< value >`.
- Для активных переключаемых настроек выводится подсказка `Enter: изменить`.
- Debug overlay в настройках не упоминается.

## Управление

- `Up/Down` или `W/S`: выбор строки.
- `Enter`: изменить выбранную настройку или активировать пункт.
- `Backspace`: удалить символ имени, когда выбрана строка имени.
