# v8 HUD centered layout fix

## Изменено

- Верхний HUD больше не привязан к координате `x=8` и центрируется относительно текущего internal render size.
- Контекстная interaction-плашка перенесена вниз экрана и центрируется по горизонтали.
- Временные HUD-сообщения также выводятся снизу и центрируются.
- Layout теперь использует `internal_width` и `internal_height`, поэтому корректно работает при изменении размеров рендера в конфиге.
