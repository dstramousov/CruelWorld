Лучшие режимы
Вариант A — рекомендую как основной
internal/render: 640x360
window:          1280x720
scale:           2x

Хороший баланс: пиксельный шрифт чёткий, окно нормального размера, UI читаемый.

Вариант B — если хочешь больше места в UI
internal/render: 800x450
window:          1600x900
scale:           2x

Очень хороший вариант для разработки. Больше места под коммуникатор, debug overlay и меню.

Вариант C — если экран Full HD и хочешь крупнее
internal/render: 640x360
window:          1920x1080
scale:           3x

Очень чётко, крупно, но UI может казаться слишком большим.

Вариант D — если хочешь больше игрового пространства на Full HD
internal/render: 960x540
window:          1920x1080
scale:           2x

Больше видимой области, меньше “крупность” UI. Хорошо, если 640x360 кажется тесным.

Вариант E — для 2K-монитора
internal/render: 640x360
window:          2560x1440
scale:           4x

Очень чётко, но всё крупное.

Или:

internal/render: 1280x720
window:          2560x1440
scale:           2x

Больше места, аккуратнее UI.

Что я бы выбрал

Для текущей игры я бы тестировал в таком порядке:

1. 640x360  -> 1280x720
2. 800x450  -> 1600x900
3. 960x540  -> 1920x1080

Мой фаворит сейчас: 800x450 render + 1600x900 window.
Это даст больше места под коммуникатор и debug overlay, но сохранит чёткий пиксельный scale 2x.

Чего избегать

Не ставь такие пары:

640x360 -> 1200x700
640x360 -> 1366x768
800x450 -> 1920x1080

Там scale получается дробный, и пиксельный шрифт будет выглядеть плохо.
